## MediaPipe Tasks Vision

DashGuard loads `@mediapipe/tasks-vision` version 1.2.3 from jsDelivr for browser-based object detection. The package is distributed under the Apache License, Version 2.0. Package source and license:

- https://www.npmjs.com/package/@mediapipe/tasks-vision
- https://github.com/google-ai-edge/mediapipe

The EfficientDet-Lite0 object model and BlazeFace full-range face model are fetched from Google's public MediaPipe model collection at runtime and are cached by the browser/service worker where supported. The models are not committed to this repository.
